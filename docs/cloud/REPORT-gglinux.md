## What changed (commits on this branch)

Build and test fixes:

- **rustfmt** had never been applied: 53 files failed `cargo fmt --check`. Applied stock rustfmt in
  one formatting-only commit (`88a6390`), listed in `.git-blame-ignore-revs`.
- **clippy** failed under `-D warnings` because an `allow` named a lint
  (`clippy::chunks_exact_to_as_chunks`) that clippy 1.97 and the 1.87 MSRV don't know. The
  attribute now also allows `unknown_lints`. No code change.
- **npm audit**: four high-severity advisories in build-time packages (vite, devalue, nanoid,
  source-map-js). Only those four lockfile entries moved, within the existing ranges.
- **gg-audio tests** failed with "permission denied" (57 tests) for any user other than the first
  to run them on a machine, because all scratch directories shared one `/tmp/gg-audio-tests`
  parent. Found by running the suite as a non-root user after root. Fixed test-first; test-only.
- **PKGBUILD** failed to link the daemon under a stock Arch `makepkg.conf`: makepkg's LTO flags turn
  hidapi's bundled C code into GCC bitcode (undefined `hid_read`, `hid_write`). Reproduced in an
  Arch container; fixed with `options=('!lto')`. This was already broken before this session.

Public-facing docs: README rewritten for newcomers (what it is, not affiliated with SteelSeries,
an honest verified/untested/blocked/parked matrix, screenshot list, requirements, install from
source and from the PKGBUILD, the narrow udev rule and the opt-in reactive rule, the user unit,
`ggctl`, uninstall); `CONTRIBUTING.md` (CI checks, fake daemon, conventions, hardware-write rules);
`SECURITY.md` (private reporting, the allowlisted HID writes and every other surface);
`CHANGELOG.md` from the full commit history; `docs/ARCHITECTURE.md`.

Hygiene: SPDX `GPL-3.0-or-later` headers on 87 files; repository URLs now
`github.com/YKKULTRA/gglinux`; a scratchpad path with the owner's home directory, a local user name
and private-note steps removed from the design docs; `.gitignore` now covers `.superpowers/` and
`.remember/`. Full list with reasons in `DECISIONS-gglinux.md` (D9).

CI: `.github/workflows/ci.yml`, two jobs (daemon; UI + Tauri), triggered only on push to
master/main, pull requests and `workflow_dispatch`.

Arch packaging: source `git+https://github.com/YKKULTRA/gglinux.git`, network only in
`prepare()`, `--frozen` builds, `!lto`, direct library dependencies listed, `.SRCINFO` generated by
makepkg, and `packaging/arch/README.md` with the AUR submission steps.

Owner checklist: `docs/PUBLISH-CHECKLIST.md` with the open decisions, two cleanup paths (both
dry-run in throwaway clones), the GitHub settings for going public, the AUR steps and the history
