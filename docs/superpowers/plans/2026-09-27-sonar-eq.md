# Sonar EQ (M3b) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-channel parametric EQ plus a shared headphone correction, edited live on a draggable curve, with AutoEQ import.

**Architecture:** Each Sonar channel becomes a `filter-chain` (preamp → 12-band headphone correction → 10-band channel EQ) instead of a loopback, keeping the M3a node names. `gg-audio::eq` owns layouts, validation, AutoEQ parsing and the `pw-cli set-param` Props string; `Sonar` stores EQ in settings and pushes it with the volumes. The UI draws the response with the same RBJ formulas PipeWire uses.

**Tech Stack:** Rust 2021, PipeWire 1.6 filter-chain builtins, Svelte 5 + SVG.

**Spec:** `docs/superpowers/specs/2026-09-27-sonar-eq-design.md`

## Global Constraints

- Stage names: `pre` (label `linear`, control `Mult` only), `hp_1`…`hp_12`, `eq_1`…`eq_10`, linked in that order; labels `bq_lowshelf` / `bq_peaking` / `bq_highshelf`.
- Channel layout [LS, PK×8, HS], gain ±12 dB; headphone layout [LS, PK×10, HS], gain and preamp ±20 dB; freq 20–20000 Hz; Q 0.1–10.
- Defaults: channel centres 31, 62, 125, 250, 500, 1000, 2000, 4000, 8000, 16000 Hz; shelves Q 0.707, peaks Q 1.0; headphone LS 105 Hz, peaks at the same ten centres, HS 10000 Hz; all 0 dB.
- Live control: `pw-cli set-param <sink id> Props "{ params = [ … ] }"` (argv, no shell); preamp sent as `"pre:Mult" 10^(dB/20)`.
- The UI curve uses RBJ with `alpha = sin(w0)/(2Q)` for all three kinds at 48 kHz.

## Review Focus

1. **AutoEQ file with two low shelves or eleven peaks** → refused with the line number, not silently truncated — test `autoeq_refuses_what_it_cannot_represent` (Task 2).
2. **A client sends bands whose kinds don't match the fixed graph** (e.g. peaking in slot 1) → refused; PipeWire can't change a filter's type live — test `validate_rejects_wrong_kinds_and_ranges` (Task 2).
3. **Upgrading from M3a with Sonar on** leaves the old loopback drop-in in place → rewritten with exactly one restart — test `an_outdated_dropin_is_rewritten_with_one_restart` (Task 4).
4. **An invalid EQ edit** must not change stored settings or send anything — test `channel_eq_is_validated_saved_and_set_live` (Task 4).
5. **EQ lost after reboot** → pushed with levels whenever channels reappear — covered by `enable_sets_every_channels_chain` plus M3a's `levels_are_restored_when_the_channels_come_back` (Task 4 extends `apply_levels`).

/// The shape of an EQ band.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum BandKind {
    LowShelf,
    Peaking,
    HighShelf,
}

/// One parametric EQ band.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct EqBand {
    pub kind: BandKind,
    /// Centre (peaking) or corner (shelf) frequency, Hz.
    pub freq: f32,
    pub q: f32,
    /// dB.
    pub gain: f32,
}

/// One channel's EQ.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct ChannelEq {
    pub channel: Channel,
    pub bands: Vec<EqBand>,
}

/// Headphone correction, shared by every channel.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct HeadphoneEq {
    /// dB applied before the bands (AutoEQ's "Preamp").
    pub preamp: f32,
    /// Low shelf, ten peaking bands, high shelf.
    pub bands: Vec<EqBand>,
    /// What it corrects, e.g. an AutoEQ headphone name.
    pub name: Option<String>,
}

```rust
//! Parametric EQ: band layouts, defaults, validation, AutoEQ import, and the
//! filter-chain parameters that set bands live.
//!
//! A filter's type is part of the graph PipeWire builds and cannot change at
//! runtime, so every channel has the same fixed chain — a preamp, the headphone
//! correction (low shelf, ten peaking, high shelf), then the channel EQ (low
//! shelf, eight peaking, high shelf) — and only frequencies, Qs and gains move.

use anyhow::{bail, ensure, Context, Result};
use gg_ipc::{BandKind, EqBand, HeadphoneEq};

/// Channel EQ reaches ±12 dB, like Sonar; headphone correction needs more room.
pub const CHANNEL_GAIN_LIMIT: f32 = 12.0;
pub const HEADPHONE_GAIN_LIMIT: f32 = 20.0;

const CENTRES: [f32; 10] = [31.0, 62.0, 125.0, 250.0, 500.0, 1000.0, 2000.0, 4000.0, 8000.0, 16000.0];

/// A 0.707 (Butterworth) shelf slope.
const SHELF_Q: f32 = 0.707;

/// Band kinds of a channel EQ, in chain order.
pub fn channel_layout() -> Vec<BandKind> {
    layout(10)
}

/// Band kinds of the headphone correction, in chain order.
pub fn headphone_layout() -> Vec<BandKind> {
    layout(12)
}

fn layout(n: usize) -> Vec<BandKind> {
    let mut kinds = vec![BandKind::Peaking; n];
    kinds[0] = BandKind::LowShelf;
    kinds[n - 1] = BandKind::HighShelf;
    kinds
}

fn flat_band(kind: BandKind, freq: f32) -> EqBand {
    let q = if kind == BandKind::Peaking { 1.0 } else { SHELF_Q };
    EqBand { kind, freq, q, gain: 0.0 }
}

/// A flat channel EQ. Every band at 0 dB is an exact passthrough.
pub fn flat_channel() -> Vec<EqBand> {
    channel_layout().into_iter().zip(CENTRES).map(|(kind, freq)| flat_band(kind, freq)).collect()
}

/// A flat headphone correction.
pub fn flat_headphone() -> HeadphoneEq {
    let mut bands = vec![flat_band(BandKind::LowShelf, 105.0)];
    bands.extend(CENTRES.iter().map(|&freq| flat_band(BandKind::Peaking, freq)));
    bands.push(flat_band(BandKind::HighShelf, 10_000.0));
    HeadphoneEq { preamp: 0.0, bands, name: None }
}

/// Check bands against a layout and the ranges the filters accept.
pub fn validate(bands: &[EqBand], layout: &[BandKind], gain_limit: f32) -> Result<()> {
    ensure!(bands.len() == layout.len(), "expected {} EQ bands, got {}", layout.len(), bands.len());
    for (i, (band, kind)) in bands.iter().zip(layout).enumerate() {
        let n = i + 1;
        ensure!(band.kind == *kind, "band {n} must be {kind:?}, not {:?}", band.kind);
        ensure!(
            band.freq.is_finite() && (20.0..=20_000.0).contains(&band.freq),
            "band {n} frequency {} Hz out of range (20..=20000)",
            band.freq
        );
        ensure!(
            band.q.is_finite() && (0.1..=10.0).contains(&band.q),
            "band {n} Q {} out of range (0.1..=10)",
            band.q
        );
        ensure!(
            band.gain.is_finite() && band.gain.abs() <= gain_limit,
            "band {n} gain {} dB out of range (±{gain_limit})",
            band.gain
        );
    }
    Ok(())
}

pub fn validate_headphone(eq: &HeadphoneEq) -> Result<()> {
    ensure!(
        eq.preamp.is_finite() && eq.preamp.abs() <= HEADPHONE_GAIN_LIMIT,
        "preamp {} dB out of range (±{HEADPHONE_GAIN_LIMIT})",
        eq.preamp
    );
    validate(&eq.bands, &headphone_layout(), HEADPHONE_GAIN_LIMIT)
}

/// Parse AutoEQ's `ParametricEQ.txt` into a headphone correction.
///
/// ```text
/// Preamp: -6.2 dB
/// Filter 1: ON LSC Fc 105 Hz Gain 7.0 dB Q 0.70
/// Filter 2: ON PK Fc 180 Hz Gain -3.4 dB Q 0.53
/// ```
///
/// Shelves go to the shelf slots and peaking filters fill the ten peaking slots
/// in order; unused slots stay flat. A second shelf of the same kind, an
/// eleventh peak, or another filter type is refused rather than approximated.
pub fn parse_autoeq(text: &str) -> Result<HeadphoneEq> {
    let mut eq = flat_headphone();
    let (mut low, mut high, mut peaks, mut any) = (false, false, 0usize, false);
    for (index, raw) in text.lines().enumerate() {
        let line_no = index + 1;
        let line = raw.trim();
        if line.is_empty() || line.starts_with('#') {
            continue;
        }
        if let Some(rest) = line.strip_prefix("Preamp:") {
            eq.preamp = number(rest.trim().trim_end_matches("dB"))
                .with_context(|| format!("line {line_no}: preamp"))?;
            continue;
        }
        ensure!(line.starts_with("Filter"), "line {line_no}: not an AutoEQ line: {line}");
        let words: Vec<&str> = line.split_whitespace().collect();
        if words.get(2) == Some(&"OFF") {
            continue;
        }
        let value = |key: &str| -> Result<f32> {
            let at = words
                .iter()
                .position(|w| *w == key)
                .with_context(|| format!("line {line_no}: no {key}"))?;
            number(words.get(at + 1).copied().unwrap_or_default())
                .with_context(|| format!("line {line_no}: {key}"))
        };
        let (freq, gain, q) = (value("Fc")?, value("Gain")?, value("Q")?);
        let slot = match words.get(3).copied() {
            Some("LSC") | Some("LS") => {
                ensure!(!low, "line {line_no}: only one low shelf fits");
                low = true;
                0
            }
            Some("HSC") | Some("HS") => {
                ensure!(!high, "line {line_no}: only one high shelf fits");
                high = true;
                11
            }
            Some("PK") | Some("PEQ") => {
                ensure!(peaks < 10, "line {line_no}: more than ten peaking filters");
                peaks += 1;
                peaks
            }
            other => bail!(
                "line {line_no}: filter type {} is not supported (PK, LSC, HSC)",
                other.unwrap_or("?")
            ),
        };
        eq.bands[slot] = EqBand { kind: eq.bands[slot].kind, freq, q, gain };
        any = true;
    }
    ensure!(any, "no filters found — paste the contents of an AutoEQ ParametricEQ.txt");
    validate_headphone(&eq)?;
    Ok(eq)
}

fn number(text: &str) -> Result<f32> {
    let value: f32 = text.trim().parse().with_context(|| format!("{text:?} is not a number"))?;
    ensure!(value.is_finite(), "{text:?} is not a finite number");
    Ok(value)
}

/// The `Props` value that sets a channel's whole chain in one `pw-cli set-param`.
pub fn props(channel: &[EqBand], headphone: &HeadphoneEq) -> String {
    let mut params = vec![format!("\"pre:Mult\" {:.6}", 10f32.powf(headphone.preamp / 20.0))];
    for (i, band) in headphone.bands.iter().enumerate() {
        params.push(band_params(&format!("hp_{}", i + 1), band));
    }
    for (i, band) in channel.iter().enumerate() {
        params.push(band_params(&format!("eq_{}", i + 1), band));
    }
    format!("{{ params = [ {} ] }}", params.join(" "))
}

fn band_params(name: &str, band: &EqBand) -> String {
    format!(
        "\"{name}:Freq\" {:.1} \"{name}:Q\" {:.3} \"{name}:Gain\" {:.2}",
        band.freq, band.q, band.gain
    )
}

/// The chain every channel runs: preamp, headphone correction, channel EQ.
/// Everything starts flat; gglinux sets the controls live.
fn filter_graph() -> String {
    let headphone = eq::flat_headphone().bands;
    let channel = eq::flat_channel();
    let stages: Vec<(String, gg_ipc::EqBand)> = headphone
        .iter()
        .enumerate()
        .map(|(i, b)| (format!("hp_{}", i + 1), *b))
        .chain(channel.iter().enumerate().map(|(i, b)| (format!("eq_{}", i + 1), *b)))
        .collect();

            label = filter_label(band.kind),
            freq = band.freq,
            q = band.q,

        std::iter::once("pre").chain(stages.iter().map(|(n, _)| n.as_str())).collect();

        .windows(2)
        .map(|w| format!(r#"            {{ output = "{}:Out" input = "{}:In" }}"#, w[0], w[1]))
        .collect();
    format!(
        "          nodes = [\n{}\n          ]\n          links = [\n{}\n          ]",
        nodes.join("\n"),
        links.join("\n")
    )
}

```ts
// Frequency response of an EQ chain, computed exactly as PipeWire's
// filter-chain filters are (spa/plugins/audioconvert/biquad.c): RBJ cookbook
// biquads with alpha = sin(w0) / 2Q for peaking bands and both shelves. What
// the editor draws is what PipeWire applies.

import type { EqBand } from "./types";

/** PipeWire's graph rate here; at 44.1 kHz the curve differs only near 20 kHz. */
const RATE = 48000;

interface Coeffs {
  b0: number;
  b1: number;
  b2: number;
  a0: number;
  a1: number;
  a2: number;
}

function coeffs(b: EqBand): Coeffs {
  const A = 10 ** (b.gain / 40);
  const w0 = (2 * Math.PI * b.freq) / RATE;
  const k = Math.cos(w0);
  const alpha = Math.sin(w0) / (2 * b.q);
  if (b.kind === "peaking") {
    return { b0: 1 + alpha * A, b1: -2 * k, b2: 1 - alpha * A, a0: 1 + alpha / A, a1: -2 * k, a2: 1 - alpha / A };
  }
  const k2 = 2 * Math.sqrt(A) * alpha;
  if (b.kind === "low_shelf") {
    return {
      b0: A * (A + 1 - (A - 1) * k + k2),
      b1: 2 * A * (A - 1 - (A + 1) * k),
      b2: A * (A + 1 - (A - 1) * k - k2),
      a0: A + 1 + (A - 1) * k + k2,
      a1: -2 * (A - 1 + (A + 1) * k),
      a2: A + 1 + (A - 1) * k - k2,
    };
  }
  return {
    b0: A * (A + 1 + (A - 1) * k + k2),
    b1: -2 * A * (A - 1 + (A + 1) * k),
    b2: A * (A + 1 + (A - 1) * k - k2),
    a0: A + 1 - (A - 1) * k + k2,
    a1: 2 * (A - 1 - (A + 1) * k),
    a2: A + 1 - (A - 1) * k - k2,
  };
}

/** |H(e^jw)| in dB at frequency f. */
function magnitudeDb(c: Coeffs, f: number): number {
  const w = (2 * Math.PI * f) / RATE;
  const cw = Math.cos(w);
  const c2w = Math.cos(2 * w);
  const num = c.b0 ** 2 + c.b1 ** 2 + c.b2 ** 2 + 2 * (c.b0 * c.b1 + c.b1 * c.b2) * cw + 2 * c.b0 * c.b2 * c2w;
  const den = c.a0 ** 2 + c.a1 ** 2 + c.a2 ** 2 + 2 * (c.a0 * c.a1 + c.a1 * c.a2) * cw + 2 * c.a0 * c.a2 * c2w;
  return 10 * Math.log10(num / den);
}

/** Combined response of a chain of bands at frequency f, in dB. A 0 dB band is flat. */
export function responseDb(bands: EqBand[], f: number): number {
  return bands.reduce((sum, b) => sum + (b.gain === 0 ? 0 : magnitudeDb(coeffs(b), f)), 0);
}

      eqTab === "headphone"
        ? daemon.setHeadphoneEq({ ...s.headphone, bands })
        : daemon.setChannelEq(eqTab, bands),
    );
  }

  function importAutoEq() {
    const text = importText;
    const name = importName.trim() || null;
    void run("import", async () => {
      await daemon.importAutoEq(text, name);
      importText = "";
    });
  }
