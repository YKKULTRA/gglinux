# Sonar mic chain (M3c) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A virtual "gglinux Mic" (RNNoise → noise gate → compressor on a physical mic) that apps record from while Sonar is on, controlled live from the Sonar tab.

**Architecture:** `gg-audio::mic` owns the module text, live Props, validation and plugin detection. The Sonar drop-in gains the mic module (only when plugins exist; `nofail`). `Sonar` picks the input, makes the mic the default input, and applies settings with the other levels. `PwTools` grows `mic_plugins_present` so tests control plugin presence.

**Tech Stack:** Rust 2021, PipeWire filter-chain (LADSPA + builtin), Svelte 5.

**Spec:** `docs/superpowers/specs/2026-09-27-sonar-mic-design.md`

## Global Constraints

- Node names: virtual source `gglinux_mic` (`Audio/Source`), capture stream `gglinux_mic.in` with `node.passive = true`, `node.dont-fallback = true`, `target.object = "<input>"`.
- Stages: `rnnoise` (ladspa `librnnoise_ladspa`, `noise_suppressor_mono`), `gate` (builtin `noisegate`), `comp` (ladspa `sc4m_1916`, `sc4m`); mono; module `flags = [ nofail ]`.
- Ranges: strength 0–95 %, gate threshold −80…−10 dB, makeup 0–18 dB. Defaults: denoise on 50 %, gate off −45 dB, compressor off 6 dB.
- Live props go to the capture node (`gglinux_mic.in`); volume to `gglinux_mic`.
- Plugins detected as `<dir>/<plugin>.so` in `LADSPA_PATH` then `/usr/lib64/ladspa`, `/usr/lib/ladspa`, `/usr/local/lib/ladspa`.

## Review Focus

1. **The physical mic disappears** → the capture must not fall back to the default input (itself): `node.dont-fallback` — test `module_is_a_mono_nofail_chain_into_a_virtual_source` (Task 2).
2. **Plugins missing or broken** → channels unaffected — tests `without_mic_plugins_the_channels_still_work` and the `nofail` assertion (Tasks 2, 5).
3. **The mic module fails to load even though plugins exist** → Sonar stays on without the mic rather than rolling back — test `channels_up_without_the_mic_keeps_sonar_on` (Task 5).
4. **Plugins installed after enabling** → the startup upgrade adds the mic once — test `plugins_installed_later_add_the_mic_on_startup` (Task 5).
5. **Out-of-range mic settings** → error, nothing stored or sent — test `mic_settings_are_validated_saved_and_set_live` (Task 5).

```rust
/// Processing on the virtual mic.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct MicSettings {
    /// RNNoise noise suppression.
    pub denoise: bool,
    /// RNNoise's voice-detection threshold, 0..=95 %: higher cuts more non-voice sound.
    pub denoise_strength: f32,
    /// Noise gate: silence below `gate_threshold_db`.
    pub gate: bool,
    /// -80..=-10 dB.
    pub gate_threshold_db: f32,
    /// Compressor (4:1 above -18 dB) plus makeup gain.
    pub compressor: bool,
    /// 0..=18 dB.
    pub makeup_db: f32,
}

impl Default for MicSettings {
    fn default() -> Self {
        MicSettings {
            denoise: true,
            denoise_strength: 50.0,
            gate: false,
            gate_threshold_db: -45.0,
            compressor: false,
            makeup_db: 6.0,
        }
    }
}

/// The virtual mic as the daemon sees it.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct MicState {
    /// Whether the mic chain's plugins are installed.
    pub available: bool,
    /// Whether PipeWire has the virtual mic right now.
    pub present: bool,
    /// `node.name` of the physical mic it reads.
    pub input: Option<String>,
    pub inputs: Vec<AudioDevice>,
    /// 0..=1 on the mixer's scale; `None` when absent.
    pub volume: Option<f32>,
    pub settings: MicSettings,
}
```

```rust
//! The virtual mic: RNNoise noise suppression → noise gate → compressor on a
//! physical mic, as a source apps record from.
//!
//! Like the channels, the chain is fixed once PipeWire builds it, so every stage
//! stays in the graph and is switched off through its own controls: RNNoise's
//! `Dry Mix` at 1, the gate's thresholds at 0 (always open), the compressor at 1:1.

use std::path::PathBuf;

use anyhow::{ensure, Result};
use gg_ipc::MicSettings;

/// The virtual source apps record from.
pub const SOURCE: &str = "gglinux_mic";
/// The stream that reads the physical mic; the filter's controls live on it.
pub const CAPTURE: &str = "gglinux_mic.in";

/// LADSPA plugins; PipeWire appends `.so` when it loads them.
const RNNOISE: &str = "librnnoise_ladspa";
const SC4M: &str = "sc4m_1916";

/// Where PipeWire looks for LADSPA plugins after `LADSPA_PATH`.
const DEFAULT_LADSPA_DIRS: [&str; 3] = ["/usr/lib64/ladspa", "/usr/lib/ladspa", "/usr/local/lib/ladspa"];

/// Compressor settings the UI does not expose.
const COMP_THRESHOLD_DB: f32 = -18.0;
const COMP_RATIO: f32 = 4.0;

/// Whether both plugins are installed, searching `LADSPA_PATH`, then the defaults.
pub fn plugins_present() -> bool {
    let mut dirs: Vec<PathBuf> = std::env::var_os("LADSPA_PATH")
        .map(|p| std::env::split_paths(&p).collect())
        .unwrap_or_default();
    dirs.extend(DEFAULT_LADSPA_DIRS.iter().map(PathBuf::from));
    plugins_present_in(&dirs)
}

/// Whether both plugins exist as files in one of `dirs`.
pub fn plugins_present_in(dirs: &[PathBuf]) -> bool {
    let found = |plugin: &str| dirs.iter().any(|d| d.join(format!("{plugin}.so")).is_file());
    found(RNNOISE) && found(SC4M)
}

pub fn validate(s: &MicSettings) -> Result<()> {
    ensure!(
        s.denoise_strength.is_finite() && (0.0..=95.0).contains(&s.denoise_strength),
        "noise suppression strength {} out of range (0..=95)",
        s.denoise_strength
    );
    ensure!(
        s.gate_threshold_db.is_finite() && (-80.0..=-10.0).contains(&s.gate_threshold_db),
        "gate threshold {} dB out of range (-80..=-10)",
        s.gate_threshold_db
    );
    ensure!(
        s.makeup_db.is_finite() && (0.0..=18.0).contains(&s.makeup_db),
        "makeup gain {} dB out of range (0..=18)",
        s.makeup_db
    );
    Ok(())
}

/// The drop-in module for a mic chain reading `input` (a source `node.name`).
///
/// `nofail`: if a plugin can't be loaded after all, PipeWire skips this module
/// and still loads the channels. `node.dont-fallback`: if the physical mic
/// disappears, the capture waits rather than falling back to the default input —
/// which, with Sonar on, is this very mic.
pub fn module(input: &str) -> Result<String> {
    crate::config::check_name(input)?;
    Ok(format!(
        r#"    {{ name = libpipewire-module-filter-chain
      flags = [ nofail ]
      args = {{
        node.description = "gglinux Mic"
        audio.channels   = 1
        audio.position   = [ MONO ]
        filter.graph = {{
          nodes = [
            {{ type = ladspa name = rnnoise plugin = "{RNNOISE}" label = noise_suppressor_mono control = {{ "VAD Threshold (%)" = 50.0 "VAD Grace Period (ms)" = 200.0 "Retroactive VAD Grace (ms)" = 0.0 "Dry Mix" = 0.0 }} }}
            {{ type = builtin name = gate label = noisegate control = {{ "Open Threshold" = 0.0 "Close Threshold" = 0.0 "Attack (s)" = 0.005 "Hold (s)" = 0.2 "Release (s)" = 0.1 }} }}
            {{ type = ladspa name = comp plugin = "{SC4M}" label = sc4m control = {{ "RMS/peak" = 0.5 "Attack time (ms)" = 5.0 "Release time (ms)" = 100.0 "Threshold level (dB)" = {COMP_THRESHOLD_DB:.1} "Ratio (1:n)" = 1.0 "Knee radius (dB)" = 3.0 "Makeup gain (dB)" = 0.0 }} }}
          ]
          links = [
            {{ output = "rnnoise:Output" input = "gate:In" }}
            {{ output = "gate:Out" input = "comp:Input" }}
          ]
        }}
        capture.props = {{
          node.name          = "{CAPTURE}"
          node.passive       = true
          target.object      = "{input}"
          node.dont-fallback = true
        }}
        playback.props = {{
          node.name   = "{SOURCE}"
          media.class = "Audio/Source"
        }}
      }}
    }}
"#
    ))
}

/// The `pw-cli set-param` Props for the chain's live controls.
pub fn props(s: &MicSettings) -> String {
    let dry = if s.denoise { 0.0 } else { 1.0 };
    let open = if s.gate { 10f32.powf(s.gate_threshold_db / 20.0) } else { 0.0 };
    // Close a little below the open level, so the gate doesn't chatter.
    let close = open * 0.7;
    let (ratio, makeup) = if s.compressor { (COMP_RATIO, s.makeup_db) } else { (1.0, 0.0) };
    format!(
        "{{ params = [ \"rnnoise:VAD Threshold (%)\" {strength:.1} \"rnnoise:Dry Mix\" {dry:.1} \
         \"gate:Open Threshold\" {open:.6} \"gate:Close Threshold\" {close:.6} \
         \"comp:Ratio (1:n)\" {ratio:.1} \"comp:Makeup gain (dB)\" {makeup:.1} ] }}",
        strength = s.denoise_strength
    )
}
```

```rust
        if !volume.is_finite() {

        self.apply_mic()

    /// Read a different physical mic, now and from the next PipeWire start.
    pub fn set_mic_input(&mut self, name: &str) -> Result<()> {
        self.refresh();
        if !self.graph.physical_sources().any(|n| n.name == name) {
            bail!("no input device named {name}");
        }
        self.settings.mic_input = Some(name.to_owned());
        self.persist();
        if self.settings.enabled {
            if let Some(output) = self.settings.output.clone() {
                let text = self.expected_dropin(&output)?;
                std::fs::write(&self.dropin_path, text)
                    .with_context(|| format!("writing {}", self.dropin_path.display()))?;
            }
            if let Some(node) = self.graph.node(mic::CAPTURE) {
                self.tools.run(&tools::set_target(node.id, name))?;
            }
        }
        Ok(())
    }
```
