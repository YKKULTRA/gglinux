# Profiles and per-game switching (M7a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** named lighting profiles, plus rules that apply a profile while a given process runs and
restore the previous lighting when it exits.

**Architecture:**
- **Scanning:** a pure `/proc` scanner (`profiles/procs.rs`).
- **Store and transitions:** a pure store plus the transition logic (`profiles/store.rs`).
- **Controller:** a tokio task (`profiles.rs`) that ticks every 2 s. It talks to the keyboard
  worker through a small `LightingPort` trait, so the switching logic is tested against an
  in-memory port.
- **IPC and UI:** requests, and a Profiles panel on the Settings page.

**Tech Stack:** Rust (tokio, serde, libc), Svelte 5.

**Spec:** `docs/superpowers/specs/2026-09-29-profiles-design.md`

**Depends on:** M6a and M6b done (stacked branch `m7a-profiles` from the M6b tip).

## Global Constraints

- `~/.config/gglinux/profiles.json` = `{profiles:[{name, lighting}], rules:[{process, profile}]}`,
  written atomically; unreadable → empty, with a warning.
- **Names:** profile names 1–64 characters after trimming; rule processes non-empty after trimming.
  `delete_profile` is refused while a rule uses the profile; `set_game_rules` is refused if a rule
  names a missing profile.
- **Scan:** every 2 s, over `/proc/<numeric pid>` owned by `getuid()`. A process's names are
  `comm` (trimmed) and the basename of `argv[0]`, split on `/` and `\`. Case-insensitive; at most
  1000 names returned.
- **Pick:** the first rule, in list order, whose lower-cased process is running and whose profile
  exists.
- **Transitions:** none → picked: `before = current`, then apply. A → B: apply B and keep `before`.
  Active → none: restore `before`. Lighting always goes through the keyboard worker's
  `GetState`/`SetLighting`.
- `running` appears only in `get_profiles` answers; events carry an empty `running`.
- **Checks and style:** as before.

## Review Focus

1. **A game whose process lingers or restarts** during loading (it exits and a new process
   appears). A 2 s scan may see a gap and restore then re-apply. That's acceptable, but the
   original lighting must never be lost: `before` survives A → none → A because it's taken again
   from the restored lighting. Pinned by the Task 4 test `restart_gaps_never_lose_the_original`.
2. **The owner deleting a profile that a rule uses.** Refused, with a message naming the rule.
   Pinned by the Task 3 test `profiles_in_use_cannot_be_deleted`.
3. **Hundreds of processes.** The scan stays under the 1000-name cap and skips non-numeric
   `/proc` entries. Pinned by the Task 2 test `only_numeric_entries_owned_by_the_user_count`.
4. **The keyboard unplugged when a game starts.** `SetLighting` still saves the settings, so the
   profile applies when the keyboard returns. No test is needed: the worker already behaves this
   way. The ledger records the decision.
5. **Proton's Windows paths in `argv[0]`.** `Z:\…\Game.exe` → `Game.exe`. Pinned by the Task 2
   test `names_come_from_comm_and_the_program_path`.

```rust
//! Which programs are running, by the names a person would recognise.

use std::collections::BTreeMap;
use std::os::unix::fs::MetadataExt;
use std::path::Path;

/// The most names `running` returns.
const MAX_NAMES: usize = 1000;

/// A process's names: its `comm`, and the file name of `argv[0]` (Proton gives
/// Windows paths, so both `/` and `\` split).
pub fn names(comm: &str, cmdline: &[u8]) -> Vec<String> {
    let mut out = Vec::new();
    let comm = comm.trim();
    if !comm.is_empty() {
        out.push(comm.to_string());
    }
    if let Some(arg0) = cmdline.split(|&b| b == 0).next().filter(|a| !a.is_empty()) {
        let arg0 = String::from_utf8_lossy(arg0);
        let base = arg0.rsplit(['/', '\\']).next().unwrap_or(&arg0).trim().to_string();
        if !base.is_empty() && !out.iter().any(|n| n.eq_ignore_ascii_case(&base)) {
            out.push(base);
        }
    }
    out
}

/// Every name of every process `uid` owns, once each (ignoring case), sorted.
pub fn running(proc_root: &Path, uid: u32) -> Vec<String> {
    let Ok(entries) = std::fs::read_dir(proc_root) else { return Vec::new() };
    let mut seen: BTreeMap<String, String> = BTreeMap::new();
    for entry in entries.flatten() {
        let pid = entry.file_name();
        if !pid.to_string_lossy().bytes().all(|b| b.is_ascii_digit()) {
            continue;
        }
        let dir = entry.path();
        if !std::fs::metadata(&dir).is_ok_and(|m| m.uid() == uid) {
            continue;
        }
        let comm = std::fs::read_to_string(dir.join("comm")).unwrap_or_default();
        let cmdline = std::fs::read(dir.join("cmdline")).unwrap_or_default();
        for n in names(&comm, &cmdline) {
            seen.entry(n.to_lowercase()).or_insert(n);
        }
    }
    seen.into_values().take(MAX_NAMES).collect()
}
```

```rust
//! Profiles and game rules, as saved, and which rule applies when.

use std::collections::HashSet;
use std::path::Path;

use gg_ipc::{GameRule, Lighting, Profile};
use serde::{Deserialize, Serialize};
use tracing::warn;

const MAX_NAME: usize = 64;

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
pub struct Store {
    #[serde(default)]
    pub profiles: Vec<Profile>,
    #[serde(default)]
    pub rules: Vec<GameRule>,
}

fn clean(name: &str, what: &str) -> Result<String, String> {
    let name = name.trim();
    if name.is_empty() || name.chars().count() > MAX_NAME {
        return Err(format!("a {what} needs 1–{MAX_NAME} characters"));
    }
    Ok(name.to_string())
}

impl Store {
    pub fn profile(&self, name: &str) -> Option<&Profile> {
        self.profiles.iter().find(|p| p.name == name)
    }

    pub fn save_profile(&mut self, name: &str, lighting: Lighting) -> Result<(), String> {
        let name = clean(name, "profile name")?;
        match self.profiles.iter_mut().find(|p| p.name == name) {
            Some(p) => p.lighting = lighting,
            None => self.profiles.push(Profile { name, lighting }),
        }
        Ok(())
    }

    pub fn delete_profile(&mut self, name: &str) -> Result<(), String> {
        if let Some(r) = self.rules.iter().find(|r| r.profile == name) {
            return Err(format!("\"{name}\" is used by the rule for {}; remove that rule first", r.process));
        }
        let before = self.profiles.len();
        self.profiles.retain(|p| p.name != name);
        if self.profiles.len() == before {
            return Err(format!("no profile named \"{name}\""));
        }
        Ok(())
    }

    pub fn set_rules(&mut self, rules: Vec<GameRule>) -> Result<(), String> {
        let rules = rules
            .into_iter()
            .map(|r| {
                let process = clean(&r.process, "process name")?;
                if self.profile(&r.profile).is_none() {
                    return Err(format!("the rule for {process} names a missing profile \"{}\"", r.profile));
                }
                Ok(GameRule { process, profile: r.profile })
            })
            .collect::<Result<Vec<_>, String>>()?;
        self.rules = rules;
        Ok(())
    }
}

pub fn load(path: &Path) -> Store {
    match std::fs::read_to_string(path) {
        Ok(text) => serde_json::from_str(&text).unwrap_or_else(|e| {
            warn!(path = %path.display(), error = %e, "ignoring unreadable profiles");
            Store::default()
        }),
        Err(_) => Store::default(),
    }
}

/// Save atomically; a failure is logged, never fatal.
pub fn save(path: &Path, store: &Store) {
    let write = || -> anyhow::Result<()> {
        if let Some(dir) = path.parent() {
            std::fs::create_dir_all(dir)?;
        }
        let tmp = path.with_extension("json.tmp");
        std::fs::write(&tmp, serde_json::to_string_pretty(store)?)?;
        std::fs::rename(&tmp, path)?;
        Ok(())
    };
    if let Err(e) = write() {
        warn!(path = %path.display(), error = %format!("{e:#}"), "could not save profiles");
    }
}

/// The first rule whose program is running and whose profile exists.
pub fn pick<'a>(store: &'a Store, running: &HashSet<String>) -> Option<&'a GameRule> {
    store
        .rules
        .iter()
        .find(|r| running.contains(&r.process.to_lowercase()) && store.profile(&r.profile).is_some())
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Action {
    Stay,
    Apply(GameRule),
    Restore,
}

pub fn decide(active: Option<&GameRule>, picked: Option<&GameRule>) -> Action {
    match (active, picked) {
        (a, Some(p)) if a != Some(p) => Action::Apply(p.clone()),
        (Some(_), None) => Action::Restore,
        _ => Action::Stay,
    }
}
```

```rust
//! Lighting profiles, and rules that switch to one while a game runs. A tokio
//! task scans running programs every 2 s and talks to the keyboard worker —
//! through [`LightingPort`], so the switching is testable without it.

mod procs;
mod store;

use std::collections::HashSet;
use std::future::Future;
use std::path::PathBuf;
use std::sync::{Arc, Mutex};
use std::time::Duration;

use gg_ipc::{Event, GameRule, Lighting, ProfilesState};
use tokio::sync::{broadcast, mpsc, oneshot};
use tracing::{info, warn};

use crate::keyboard::{self, Command as KeyboardCommand};
use store::{decide, pick, Action, Store};

const SCAN_EVERY: Duration = Duration::from_secs(2);

type Reply<T> = oneshot::Sender<Result<T, String>>;

/// How profiles read and set the keyboard's lighting.
pub trait LightingPort: Send + Sync + 'static {
    fn get(&self) -> impl Future<Output = Result<Lighting, String>> + Send;
    fn set(&self, lighting: Lighting) -> impl Future<Output = Result<(), String>> + Send;
}

impl LightingPort for keyboard::Handle {
    async fn get(&self) -> Result<Lighting, String> {
        self.send(KeyboardCommand::GetState).await.map(|s| s.lighting)
    }
    async fn set(&self, lighting: Lighting) -> Result<(), String> {
        self.send::<()>(|reply| KeyboardCommand::SetLighting { lighting, reply }).await
    }
}

pub enum Command {
    GetState(Reply<ProfilesState>),
    Save { name: String, reply: Reply<()> },
    Apply { name: String, reply: Reply<()> },
    Delete { name: String, reply: Reply<()> },
    SetRules { rules: Vec<GameRule>, reply: Reply<()> },
}

#[derive(Clone)]
pub struct Handle {
    tx: mpsc::UnboundedSender<Command>,
}

impl Handle {
    pub async fn send<T>(&self, make: impl FnOnce(Reply<T>) -> Command) -> Result<T, String> {
        let (reply_tx, reply_rx) = oneshot::channel();
        self.tx.send(make(reply_tx)).map_err(|_| "profiles are not running".to_string())?;
        reply_rx.await.map_err(|_| "profiles dropped the request".to_string())?
    }
}

pub struct Controller<P> {
    store: Store,
    path: PathBuf,
    port: P,
    event_tx: broadcast::Sender<Event>,
    /// The rule applied now, and the lighting to go back to.
    active: Option<GameRule>,
    before: Option<Lighting>,
    published: Option<ProfilesState>,
}

impl<P: LightingPort> Controller<P> {
    pub fn new(store: Store, path: PathBuf, port: P, event_tx: broadcast::Sender<Event>) -> Self {
        Controller { store, path, port, event_tx, active: None, before: None, published: None }
    }

    /// Apply or undo game rules for what's running (lower-cased names).
    pub async fn follow(&mut self, running: &HashSet<String>) {
        let picked = pick(&self.store, running).cloned();
        match decide(self.active.as_ref(), picked.as_ref()) {
            Action::Stay => {}
            Action::Apply(rule) => {
                if self.active.is_none() {
                    match self.port.get().await {
                        Ok(l) => self.before = Some(l),
                        Err(e) => return warn!(error = %e, "could not read the lighting before a game rule"),
                    }
                }
                let lighting = self.store.profile(&rule.profile).map(|p| p.lighting.clone());
                if let Some(lighting) = lighting {
                    if let Err(e) = self.port.set(lighting).await {
                        return warn!(error = %e, "could not apply a game profile");
                    }
                    info!(process = %rule.process, profile = %rule.profile, "game rule applied");
                    self.active = Some(rule);
                }
            }
            Action::Restore => {
                if let Some(l) = self.before.take() {
                    if let Err(e) = self.port.set(l).await {
                        warn!(error = %e, "could not restore the lighting after a game");
                    }
                }
                info!("game rule ended; lighting restored");
                self.active = None;
            }
        }
        self.publish();
    }

    pub async fn apply(&mut self, name: &str) -> Result<(), String> {
        let lighting = self.store.profile(name).ok_or_else(|| format!("no profile named \"{name}\""))?.lighting.clone();
        self.port.set(lighting).await
    }

    pub async fn save_current(&mut self, name: &str) -> Result<(), String> {
        let lighting = self.port.get().await?;
        self.store.save_profile(name, lighting)?;
        store::save(&self.path, &self.store);
        self.publish();
        Ok(())
    }

    async fn handle(&mut self, command: Command) {
        match command {
            Command::GetState(reply) => {
                let running = tokio::task::spawn_blocking(|| procs::running(std::path::Path::new("/proc"), unsafe { libc::getuid() }))
                    .await
                    .unwrap_or_default();
                let _ = reply.send(Ok(ProfilesState { running, ..self.state() }));
            }
            Command::Save { name, reply } => {
                let _ = reply.send(self.save_current(&name).await);
            }
            Command::Apply { name, reply } => {
                let _ = reply.send(self.apply(&name).await);
            }
            Command::Delete { name, reply } => {
                let result = self.store.delete_profile(&name);
                self.after_edit(result, reply);
            }
            Command::SetRules { rules, reply } => {
                let result = self.store.set_rules(rules);
                self.after_edit(result, reply);
            }
        }
    }

    fn after_edit(&mut self, result: Result<(), String>, reply: Reply<()>) {
        if result.is_ok() {
            store::save(&self.path, &self.store);
        }
        let _ = reply.send(result);
        self.publish();
    }

    fn state(&self) -> ProfilesState {
        ProfilesState {
            profiles: self.store.profiles.iter().map(|p| p.name.clone()).collect(),
            rules: self.store.rules.clone(),
            active: self.active.clone(),
            running: Vec::new(),
        }
    }

    fn publish(&mut self) {
        let now = self.state();
        if self.published.as_ref() != Some(&now) {
            self.published = Some(now.clone());
            let _ = self.event_tx.send(Event::ProfilesChanged { state: now });
        }
    }
}

pub fn spawn(event_tx: broadcast::Sender<Event>, keyboard: keyboard::Handle) -> Handle {
    let (tx, mut rx) = mpsc::unbounded_channel();
    let path = gg_ipc::config_dir().join("profiles.json");
    let mut c = Controller::new(store::load(&path), path, keyboard, event_tx);
    tokio::spawn(async move {
        let mut tick = tokio::time::interval(SCAN_EVERY);
        loop {
            tokio::select! {
                command = rx.recv() => match command {
                    Some(command) => c.handle(command).await,
                    None => break,
                },
                _ = tick.tick() => {
                    if c.store.rules.is_empty() && c.active.is_none() {
                        continue; // nothing to watch for
                    }
                    let names = tokio::task::spawn_blocking(|| procs::running(std::path::Path::new("/proc"), unsafe { libc::getuid() }))
                        .await
                        .unwrap_or_default();
                    let running: HashSet<String> = names.iter().map(|n| n.to_lowercase()).collect();
                    c.follow(&running).await;
                }
            }
        }
    });
    Handle { tx }
}
```
