# Clips (M7b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an instant-replay buffer via `gpu-screen-recorder`, saved by a hotkey, the UI or
`ggctl`, with a clip library on the Moments page.

**Architecture:**
- **Pure helpers** (`clips/recorder.rs`): the command line, the restart backoff, the clip listing,
  and safe clip paths.
- **Controller** (`clips.rs`): a tokio task that supervises the recorder child. A waiter task per
  child reports its exit on an internal channel, which keeps the `select!` loop simple. Signals go
  through `libc::kill`.
- **Hotkey** (`clips/hotkey.rs`): the GlobalShortcuts portal, via `ashpd`.
- **UI:** the Moments page, plus a Tauri `open_folder` command.

**Tech Stack:** Rust (tokio process, libc, ashpd), Svelte 5, Tauri 2.

**Spec:** `docs/superpowers/specs/2026-09-29-clips-design.md`

**Depends on:** M7a done (stacked branch `m7b-clips`).

## Global Constraints

- **Recorder command line:**
  `gpu-screen-recorder -w portal -restore-portal-session yes -c mp4 -f <fps> -r <seconds> -q <quality> -o <dir>`,
  plus `-a default_output` when `desktop_audio` and `-a default_input` when `mic`.
- **Settings defaults:** off, 30 s (5–300), 60 fps (15–240), `high`, desktop audio on, mic off,
  dir `None` → `~/Videos/gglinux`. A given `dir` must be absolute. Saved in `clips.json`, with
  `#[serde(default)]` on the struct.
- **Restarting:** 5 s after an unexpected exit, doubling to 60 s. A run of 60 s or more resets the
  delay to 5 s.
- **Stopping:** `SIGINT`, wait up to 3 s, then `SIGKILL`.
- **Saving:** `SIGUSR1`, then re-read the list after 1.5 s.
- **Listing:** files with extensions `mp4`, `mkv` or `webm` (any case), newest first, at most 200.
- **Deleting:** a plain file name (no `/`, not empty, `.` or `..`) with a video extension, existing
  in `dir`.
- **Hotkey:** shortcut id `save-clip`, description "Save the last clip", preferred trigger `ALT+S`.
  Failures are logged once and surfaced as `hotkey: None` plus an `error` note.
- **Never run `gpu-screen-recorder` for real in tests,** and never install it; the owner does that.
  In-process tests use a stand-in shell script.
- **Checks and style:** as before.

## Review Focus

1. **`gpu-screen-recorder` crashing in a loop** (portal refused, encoder missing). The backoff
   grows to 60 s and the error shows in the UI, with no restart storm. Pinned by the Task 2 test
   `restarts_back_off_and_a_long_run_resets_them`, plus the Task 3 test
   `an_unexpected_exit_is_reported_and_retried`.
2. **A delete request with `../`, or a name outside the folder.** Refused. Pinned by the Task 2
   test `only_plain_video_names_in_the_folder_can_be_deleted`.
3. **Clips turned off while recording.** The child gets `SIGINT`, not `SIGKILL`, so the file being
   written isn't corrupted. Pinned by the Task 3 test `turning_clips_off_interrupts_the_recorder`.
4. **Save pressed while clips are off.** A clear error, no signal sent anywhere. Pinned by the
   Task 3 test `saving_while_off_is_an_error`.
5. **A PID reused after the child died.** Signals go only to a child the controller still believes
   is running. The waiter's exit notice clears `running` before any later signal. Covered by
   design; the ledger records it.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ClipQuality {
    Medium,
    High,
    VeryHigh,
    Ultra,
}

/// The instant-replay recorder's settings.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct ClipsSettings {
    /// Off by default: while on, the screen is kept in a rolling buffer.
    pub enabled: bool,
    /// How much a saved clip holds.
    pub seconds: u32,
    pub fps: u32,
    pub quality: ClipQuality,
    pub desktop_audio: bool,
    pub mic: bool,
    /// Absolute folder; `None` means `~/Videos/gglinux`.
    pub dir: Option<String>,
}

impl Default for ClipsSettings {
    fn default() -> Self {
        ClipsSettings { enabled: false, seconds: 30, fps: 60, quality: ClipQuality::High, desktop_audio: true, mic: false, dir: None }
    }
}

impl ClipsSettings {
    pub const SECONDS: std::ops::RangeInclusive<u32> = 5..=300;
    pub const FPS: std::ops::RangeInclusive<u32> = 15..=240;

    pub fn validate(&self) -> Result<(), String> {
        if !Self::SECONDS.contains(&self.seconds) {
            return Err(format!("clip length {} s out of range (5..=300)", self.seconds));
        }
        if !Self::FPS.contains(&self.fps) {
            return Err(format!("{} fps out of range (15..=240)", self.fps));
        }
        if let Some(dir) = &self.dir {
            if !std::path::Path::new(dir).is_absolute() {
                return Err(format!("the clips folder must be an absolute path, not {dir:?}"));
            }
        }
        Ok(())
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct ClipInfo {
    pub name: String,
    pub bytes: u64,
    /// Seconds since the Unix epoch.
    pub modified: u64,
}

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
pub struct ClipsState {
    /// `gpu-screen-recorder` is installed.
    pub available: bool,
    pub enabled: bool,
    /// The recorder is running now.
    pub recording: bool,
    pub settings: ClipsSettings,
    /// The folder clips go to.
    pub dir: String,
    pub clips: Vec<ClipInfo>,
    /// The last thing that went wrong, for the UI.
    pub error: Option<String>,
    /// The hotkey KDE bound, if any.
    pub hotkey: Option<String>,
}
```

```rust
//! The replay recorder's command line, restart pacing, and clip files. Pure,
//! apart from reading and writing its own files.

use std::ffi::OsStr;
use std::path::{Path, PathBuf};
use std::time::{Duration, UNIX_EPOCH};

use gg_ipc::{ClipInfo, ClipQuality, ClipsSettings};
use tracing::warn;

pub const PROGRAM: &str = "gpu-screen-recorder";
const MIN_DELAY: Duration = Duration::from_secs(5);
const MAX_DELAY: Duration = Duration::from_secs(60);
const HEALTHY_RUN: Duration = Duration::from_secs(60);
const VIDEO: [&str; 3] = ["mp4", "mkv", "webm"];
const MAX_CLIPS: usize = 200;

pub fn argv(s: &ClipsSettings, dir: &Path) -> Vec<String> {
    let quality = match s.quality {
        ClipQuality::Medium => "medium",
        ClipQuality::High => "high",
        ClipQuality::VeryHigh => "very_high",
        ClipQuality::Ultra => "ultra",
    };
    let mut v: Vec<String> = [
        PROGRAM, "-w", "portal", "-restore-portal-session", "yes", "-c", "mp4",
        "-f", &s.fps.to_string(), "-r", &s.seconds.to_string(), "-q", quality, "-o", &dir.to_string_lossy(),
    ]
    .iter()
    .map(|x| x.to_string())
    .collect();
    if s.desktop_audio {
        v.extend(["-a".to_string(), "default_output".to_string()]);
    }
    if s.mic {
        v.extend(["-a".to_string(), "default_input".to_string()]);
    }
    v
}

pub fn resolve_dir(s: &ClipsSettings, home: &Path) -> PathBuf {
    s.dir.as_deref().map(PathBuf::from).unwrap_or_else(|| home.join("Videos/gglinux"))
}

/// How long to wait before restarting a recorder that ran for `ran_for` and died.
pub fn next_delay(ran_for: Duration, previous: Duration) -> Duration {
    if ran_for >= HEALTHY_RUN {
        MIN_DELAY
    } else {
        (previous * 2).clamp(MIN_DELAY, MAX_DELAY)
    }
}

fn is_video(name: &str) -> bool {
    Path::new(name).extension().and_then(OsStr::to_str).is_some_and(|e| VIDEO.iter().any(|v| v.eq_ignore_ascii_case(e)))
}

pub fn list(dir: &Path) -> Vec<ClipInfo> {
    let Ok(entries) = std::fs::read_dir(dir) else { return Vec::new() };
    let mut clips: Vec<ClipInfo> = entries
        .flatten()
        .filter_map(|e| {
            let name = e.file_name().to_string_lossy().into_owned();
            let meta = e.metadata().ok()?;
            (meta.is_file() && is_video(&name)).then(|| ClipInfo {
                name,
                bytes: meta.len(),
                modified: meta.modified().ok().and_then(|t| t.duration_since(UNIX_EPOCH).ok()).map_or(0, |d| d.as_secs()),
            })
        })
        .collect();
    clips.sort_by(|a, b| b.modified.cmp(&a.modified).then_with(|| a.name.cmp(&b.name)));
    clips.truncate(MAX_CLIPS);
    clips
}

/// The file a delete request may touch: a plain video name that exists in `dir`.
pub fn clip_path(dir: &Path, name: &str) -> Result<PathBuf, String> {
    if name.is_empty() || name == "." || name == ".." || name.contains('/') || !is_video(name) {
        return Err(format!("{name:?} is not a clip name"));
    }
    let p = dir.join(name);
    if !p.is_file() {
        return Err(format!("no clip named {name}"));
    }
    Ok(p)
}

pub fn find_program(path_var: Option<&OsStr>) -> Option<PathBuf> {
    std::env::split_paths(path_var?).map(|d| d.join(PROGRAM)).find(|p| p.is_file())
}

pub fn load(path: &Path) -> ClipsSettings {
    match std::fs::read_to_string(path) {
        Ok(text) => serde_json::from_str(&text).unwrap_or_else(|e| {
            warn!(path = %path.display(), error = %e, "ignoring unreadable clip settings");
            ClipsSettings::default()
        }),
        Err(_) => ClipsSettings::default(),
    }
}

pub fn save(path: &Path, s: &ClipsSettings) {
    let write = || -> anyhow::Result<()> {
        if let Some(dir) = path.parent() {
            std::fs::create_dir_all(dir)?;
        }
        let tmp = path.with_extension("json.tmp");
        std::fs::write(&tmp, serde_json::to_string_pretty(s)?)?;
        std::fs::rename(&tmp, path)?;
        Ok(())
    };
    if let Err(e) = write() {
        warn!(path = %path.display(), error = %format!("{e:#}"), "could not save clip settings");
    }
}
```

```rust
        script
    }
```

```rust
//! Instant replay: a supervised `gpu-screen-recorder` in replay mode, saved
//! on `SIGUSR1`. Off by default. A waiter task per child reports its exit, so
//! the controller's loop only ever waits on channels and one timer.

mod hotkey;
mod recorder;

use std::path::PathBuf;
use std::time::{Duration, Instant};

use gg_ipc::{ClipsSettings, ClipsState, Event};
use tokio::process::Command as Process;
use tokio::sync::{broadcast, mpsc, oneshot};
use tracing::{info, warn};

type Reply<T> = oneshot::Sender<Result<T, String>>;

const STOP_GRACE: Duration = Duration::from_secs(3);
const SAVE_SETTLE: Duration = Duration::from_millis(1500);

pub enum Command {
    GetState(Reply<ClipsState>),
    SetSettings { settings: ClipsSettings, reply: Reply<()> },
    Save(Reply<()>),
    Delete { name: String, reply: Reply<()> },
    /// Stop the recorder before the daemon exits; it's a separate process.
    Shutdown(Reply<()>),
}

pub enum Internal {
    Exited { generation: u64 },
    Refresh,
    Hotkey(Result<String, String>),
    SaveFromHotkey,
}

#[derive(Clone)]
pub struct Handle {
    tx: mpsc::UnboundedSender<Command>,
}

impl Handle {
    pub async fn send<T>(&self, make: impl FnOnce(Reply<T>) -> Command) -> Result<T, String> {
        let (reply_tx, reply_rx) = oneshot::channel();
        self.tx.send(make(reply_tx)).map_err(|_| "clips are not running".to_string())?;
        reply_rx.await.map_err(|_| "clips dropped the request".to_string())?
    }
}

struct Running {
    pid: i32,
    generation: u64,
    started: Instant,
    exited: oneshot::Receiver<()>,
}

pub struct Controller {
    settings: ClipsSettings,
    path: PathBuf,
    /// Set in tests; `None` searches `PATH`.
    program: Option<PathBuf>,
    event_tx: broadcast::Sender<Event>,
    internal_tx: mpsc::UnboundedSender<Internal>,
    running: Option<Running>,
    generation: u64,
    delay: Duration,
    retry_at: Option<Instant>,
    error: Option<String>,
    hotkey: Option<String>,
    hotkey_task: Option<tokio::task::JoinHandle<()>>,
    published: Option<ClipsState>,
}

fn home() -> PathBuf {
    std::env::var_os("HOME").map(PathBuf::from).unwrap_or_default()
}

fn signal(pid: i32, sig: i32) {
    // SAFETY: plain kill(2) on a child this controller started and still believes is running.
    unsafe {
        libc::kill(pid, sig);
    }
}

impl Controller {
    /// The controller, and the receiver for its internal messages (kept apart so
    /// the task's `select!` can wait on it while handlers borrow the controller).
    pub fn new(
        settings: ClipsSettings,
        path: PathBuf,
        program: Option<PathBuf>,
        event_tx: broadcast::Sender<Event>,
    ) -> (Self, mpsc::UnboundedReceiver<Internal>) {
        let (internal_tx, internal_rx) = mpsc::unbounded_channel();
        let c = Controller {
            settings, path, program, event_tx, internal_tx,
            running: None, generation: 0, delay: Duration::ZERO, retry_at: None,
            error: None, hotkey: None, hotkey_task: None, published: None,
        };
        (c, internal_rx)
    }

    fn program(&self) -> Option<PathBuf> {
        self.program.clone().or_else(|| recorder::find_program(std::env::var_os("PATH").as_deref()))
    }

    fn dir(&self) -> PathBuf {
        recorder::resolve_dir(&self.settings, &home())
    }

    pub async fn start(&mut self) {
        if self.running.is_some() || !self.settings.enabled {
            return;
        }
        let Some(program) = self.program() else {
            self.error = Some("gpu-screen-recorder is not installed".into());
            return self.publish();
        };
        let dir = self.dir();
        if let Err(e) = std::fs::create_dir_all(&dir) {
            self.error = Some(format!("cannot create {}: {e}", dir.display()));
            return self.publish();
        }
        let argv = recorder::argv(&self.settings, &dir);
        let mut child = match Process::new(&program).args(&argv[1..]).kill_on_drop(false).spawn() {
            Ok(c) => c,
            Err(e) => {
                self.error = Some(format!("could not start gpu-screen-recorder: {e}"));
                return self.publish();
            }
        };
        let pid = child.id().map_or(0, |p| p as i32);
        self.generation += 1;
        let generation = self.generation;
        let (exited_tx, exited) = oneshot::channel();
        let internal = self.internal_tx.clone();
        tokio::spawn(async move {
            let _ = child.wait().await;
            let _ = exited_tx.send(());
            let _ = internal.send(Internal::Exited { generation });
        });
        info!(pid, "replay buffer recording");
        self.running = Some(Running { pid, generation, started: Instant::now(), exited });
        self.error = None;
        self.retry_at = None;
        self.ensure_hotkey();
        self.publish();
    }

    pub async fn stop(&mut self) {
        if let Some(mut r) = self.running.take() {
            signal(r.pid, libc::SIGINT);
            if tokio::time::timeout(STOP_GRACE, &mut r.exited).await.is_err() {
                warn!("gpu-screen-recorder ignored SIGINT; killing it");
                signal(r.pid, libc::SIGKILL);
                let _ = tokio::time::timeout(Duration::from_secs(1), &mut r.exited).await;
            }
            info!("replay buffer stopped");
        }
        self.retry_at = None;
        self.publish();
    }

    pub async fn save(&mut self) -> Result<(), String> {
        let Some(r) = &self.running else {
            return Err(if self.settings.enabled { "the recorder isn't running".into() } else { "clips are off".into() });
        };
        signal(r.pid, libc::SIGUSR1);
        let internal = self.internal_tx.clone();
        tokio::spawn(async move {
            tokio::time::sleep(SAVE_SETTLE).await;
            let _ = internal.send(Internal::Refresh);
        });
        Ok(())
    }

    pub async fn set_settings(&mut self, settings: ClipsSettings) -> Result<(), String> {
        settings.validate()?;
        let changed = settings != self.settings;
        self.settings = settings;
        recorder::save(&self.path, &self.settings);
        if changed {
            self.stop().await;
            self.delay = Duration::ZERO;
            if self.settings.enabled {
                self.start().await;
            } else if let Some(t) = self.hotkey_task.take() {
                t.abort();
                self.hotkey = None;
            }
        }
        Ok(())
    }

    pub async fn on_internal(&mut self, msg: Internal) {
        match msg {
            Internal::Exited { generation } => {
                if self.running.as_ref().is_some_and(|r| r.generation == generation) {
                    let r = self.running.take().expect("checked");
                    self.delay = recorder::next_delay(r.started.elapsed(), self.delay);
                    self.retry_at = Some(Instant::now() + self.delay);
                    self.error = Some(format!("gpu-screen-recorder stopped; retrying in {} s", self.delay.as_secs()));
                    warn!(delay_s = self.delay.as_secs(), "gpu-screen-recorder stopped unexpectedly");
                }
            }
            Internal::Refresh => {}
            Internal::Hotkey(result) => match result {
                Ok(trigger) => self.hotkey = Some(trigger),
                Err(e) => {
                    self.hotkey = None;
                    self.error = Some(format!("no hotkey ({e}); use the button or `ggctl clip save`"));
                }
            },
            Internal::SaveFromHotkey => {
                if let Err(e) = self.save().await {
                    warn!(error = %e, "hotkey save failed");
                }
            }
        }
        self.publish();
    }

    fn ensure_hotkey(&mut self) {
        if self.hotkey_task.is_some() {
            return;
        }
        let internal = self.internal_tx.clone();
        self.hotkey_task = Some(tokio::spawn(hotkey::run(internal)));
    }

    pub fn state(&self) -> ClipsState {
        let dir = self.dir();
        ClipsState {
            available: self.program().is_some(),
            enabled: self.settings.enabled,
            recording: self.running.is_some(),
            settings: self.settings.clone(),
            dir: dir.to_string_lossy().into_owned(),
            clips: recorder::list(&dir),
            error: self.error.clone(),
            hotkey: self.hotkey.clone(),
        }
    }

    fn publish(&mut self) {
        let now = self.state();
        if self.published.as_ref() != Some(&now) {
            self.published = Some(now.clone());
            let _ = self.event_tx.send(Event::ClipsChanged { state: now });
        }
    }

    async fn handle(&mut self, command: Command) {
        match command {
            Command::GetState(reply) => {
                let _ = reply.send(Ok(self.state()));
            }
            Command::SetSettings { settings, reply } => {
                let _ = reply.send(self.set_settings(settings).await);
            }
            Command::Save(reply) => {
                let _ = reply.send(self.save().await);
            }
            Command::Delete { name, reply } => {
                let result = recorder::clip_path(&self.dir(), &name)
                    .and_then(|p| std::fs::remove_file(&p).map_err(|e| format!("could not delete {name}: {e}")));
                let _ = reply.send(result);
                self.publish();
            }
            Command::Shutdown(reply) => {
                self.stop().await;
                let _ = reply.send(Ok(()));
            }
        }
    }
}

pub fn spawn(event_tx: broadcast::Sender<Event>) -> Handle {
    let (tx, mut rx) = mpsc::unbounded_channel();
    let path = gg_ipc::config_dir().join("clips.json");
    let (mut c, mut internal) = Controller::new(recorder::load(&path), path, None, event_tx);
    tokio::spawn(async move {
        c.start().await;
        loop {
            let retry = c.retry_at;
            tokio::select! {
                command = rx.recv() => match command {
                    Some(command) => c.handle(command).await,
                    None => break,
                },
                Some(msg) = internal.recv() => c.on_internal(msg).await,
                _ = async { tokio::time::sleep_until(retry.expect("guarded").into()).await }, if retry.is_some() => {
                    c.retry_at = None;
                    c.start().await;
                }
            }
        }
        c.stop().await;
    });
    Handle { tx }
}
```

```rust
//! The save-clip hotkey, through the GlobalShortcuts portal: the daemon never
//! sees the keyboard (reactive lighting's security choice), so KDE does.

use ashpd::desktop::global_shortcuts::{GlobalShortcuts, NewShortcut};
use futures_util::StreamExt;
use tokio::sync::mpsc;

use super::Internal;

const ID: &str = "save-clip";

pub async fn run(internal: mpsc::UnboundedSender<Internal>) {
    if let Err(e) = bind(&internal).await {
        let _ = internal.send(Internal::Hotkey(Err(e.to_string())));
    }
}

async fn bind(internal: &mpsc::UnboundedSender<Internal>) -> ashpd::Result<()> {
    let portal = GlobalShortcuts::new().await?;
    let session = portal.create_session().await?;
    let shortcut = NewShortcut::new(ID, "Save the last clip").preferred_trigger("ALT+S");
    let bound = portal.bind_shortcuts(&session, &[shortcut], None).await?.response()?;
    let trigger = bound
        .shortcuts()
        .iter()
        .find(|s| s.id() == ID)
        .map(|s| s.trigger_description().to_string())
        .unwrap_or_else(|| "bound".into());
    let _ = internal.send(Internal::Hotkey(Ok(trigger)));
    let mut activations = portal.receive_activated().await?;
    while let Some(a) = activations.next().await {
        if a.shortcut_id() == ID {
            let _ = internal.send(Internal::SaveFromHotkey);
        }
    }
    Ok(())
}
```

## Hardware acceptance (the owner)

1. `sudo pacman -S gpu-screen-recorder`.
2. Moments → turn it on; accept KDE's screen-share dialog, and the shortcut dialog for Alt+S.
3. Play something, then press Alt+S: within 2 s a new clip shows in the list and in
   `~/Videos/gglinux`. It plays with sound.
4. Delete it from the list. Turn clips off: `pgrep gpu-screen-recorder` finds nothing.
